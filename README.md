# ГРЯЗЬ

Онлайн-игра для компании от 3 до 10 человек. Вопросы — из колоды. Ответы — из вашей головы.

## Как играть

1. Один игрок создаёт комнату, ставит пароль и отправляет друзьям приглашение.
2. Каждый раунд один из игроков по очереди становится судьёй и тянет случайный вопрос из колоды.
3. Остальные пишут на чистой карте свой ответ — своими словами, без готовых вариантов.
4. Судья переворачивает карты без имён, читает их вслух и выбирает самый смешной ответ. Автор получает очко.
5. Побеждает тот, кто первым наберёт 5, 7 или 10 очков — это выбирает хозяин комнаты.

Колоды две: «Приличная» и «Злая 18+». Время на ответ — 45, 60 или 90 секунд.

## Запуск у себя

```bash
npm install
npm start          # http://localhost:3000
npm test           # проверки правил и сетевой игры
```

Нужен Node.js 20 или новее.

## Устройство

- `server/game.js` — правила: комната, раунды, судья, ответы, очки, таймеры.
- `server/decks.js` — колоды вопросов. `___` — место для ответа игрока.
- `server/index.js` — HTTP-сервер и WebSocket `/ws`.
- `public/` — клиент без сборки: `app.js`, `style.css`, звуки на Web Audio (`sound.js`), конфетти (`fx.js`), логотип и иконки.
- `render.yaml` — рецепт для бесплатного Render: каждое изменение в `main` выкатывается само.

Комнаты живут в памяти сервера: после перезапуска или засыпания бесплатного сервера они исчезают.
